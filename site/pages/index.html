Free software for Hyprland/MIT

The rest of your Hyprland desktop.

Hyprland gives you a superb compositor and leaves the rest to you: the lock screen, the login, notifications, somewhere to change a setting. Hyprforge is that rest, made as one piece so it looks and behaves like one.

Install it → Read the source

Arch packages, or build from source · needs Hyprland 0.55 or later with a Lua config

§1What's in it

Twelve pieces, and you can take any one of them.

Each piece has its own repository and its own package. Take the clipboard history and leave the other eleven, and it'll still work and still look right. Take all twelve and they share a look, a keyboard grammar and a set of libraries, so they feel like they came from the same place, because they did.

§3How it's made

Every mistake gets written down.

The repository keeps a running list called "the rules that came from being wrong." Each entry is a real bug: what happened, why it wasn't obvious, and what now stops it happening again. Three of them:

the lock screen

A keysym name is the password.

Logging "just the keysym" while debugging sounds harmless, until you notice that XK_a is the letter a and XK_comma is a comma.

Nothing derived from a keystroke reaches a log or a crash report. What you typed shows as a count.

your config

Unreadable isn't empty.

An import once treated a config file it couldn't parse as one with nothing in it, and that cost a user 37 keybinds they'd written by hand.

A missing file means first run. A broken one gets reported to you, and nothing is written over it.

the lock screen, again

A round number is someone else's timeout.

The lock screen took five seconds to appear, and our side finished in a millisecond. The compositor was waiting for windows we were holding back.

Measure before optimising anything that talks to another process.

§4Getting it

One command, and you approve every step.

The installer builds what you ask for, copies only what changed, and checks the copy actually landed. Then it offers to wire each piece into your desktop: services, keybinds, the lock in hypridle, default apps. It asks first every time and keeps a record, so all of it can be undone.

The full install guide →

$ git clone --recurse-submodules \
    https://github.com/hyprforge-suite/hyprforge
$ cd hyprforge
$ ./hyprforge --install --all --dry-run   # look first
$ ./hyprforge --install --all
