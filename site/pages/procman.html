What's in it/hyprforge-procman

What's running, what it costs, and what it was.

Task Manager is where it starts: your apps grouped by their windows, every core and disk and GPU, services, startup. Then it does what a desktop task manager can't: atop's screen in a terminal, and a history of the whole machine you can go back through.

Install it → Source on GitHub
§1What it does
Apps by their windows
Hyprland says which process owns each window, so an app is everything it started, with the window's title under it. Then background processes, then the kernel's.
Every GPU, asleep or awake
Which card each app is using and how hard. A laptop's NVIDIA card is read only while it's already awake, so looking never wakes it.
Services, beside their processes
System and user units with the CPU and memory of their own cgroups, failed ones first, and the journal next to them.
Never the wrong process
Ending a process goes through a handle to that exact process, so a number the system has since given to something else is never hit.
Everyone's, when you ask
Show everything asks for your password once and fills in other users' disk, network and open files, through a small helper that checks with polkit every time.
Network per process
Counted in the kernel at the point each program hands data to a socket, so video calls and QUIC count, not just TCP.
§2In a terminal

atop's screen, and atop's keys.

hyprforge-top is for when there's no desktop to open a window on: over SSH, on a spare console, in a recovery shell. The header lines and views are atop's, and so are the keys, so you don't have to learn anything new.

hyprforge-top report adds up a day, ten minutes at a time: CPU, memory, disks, network, pressure, and the programs that used the most. As text, or as JSON for something else to read.

§3The hard part

What was it doing at 3 a.m.?

A task manager only shows now. The recorder keeps a record of every process every ten seconds, about 30 MB a day and under half a percent of one core. The Recorded tab draws a day and marks where the machine was struggling. Pick a moment and see what was busiest, and what the hour around it added up to.

That record has every program's command line in it, and command lines can hold passwords. So it's readable by root alone, where atop's own logs are readable by anyone. You get it through the same password prompt as Show everything. It's off until you switch it on in Set up.
